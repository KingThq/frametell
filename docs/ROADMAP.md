# 路线图

一步一步来，每一步都能独立验证。

## M1 · 引擎（packages/engine）
- [ ] 从 kit 迁入运行时、模板、工具；去掉个人内容（课程流程、个人音色、私有路径）
- [ ] 渲染改为 `playwright-core` + 系统浏览器探测 + `ffmpeg-static`
- [ ] lint 增加字号检查（正文 < 28px 报错）与空框检查
- [ ] 组件库 `lib/` 与索引；五套风格包：安静书房、白板手绘、黑板、科技深色、暖调叙事插画
- [ ] 用一个固定的示例项目做回归：能渲染、能截图、lint 结果稳定

## M1.5 · 质量体系（见 QUALITY.md）
- [ ] 分镜改为拍点结构 + 分镜 lint（版面词、万能动词、屏上字、首尾页、数字溯源、节奏）
- [ ] 页面 lint 补齐：空框、文字主导面积、画面饱满度、推拉切字、确定性双渲
- [ ] 成片门禁（Node + ffmpeg）：空画面、快动帧占比；用作者表态片标定
- [ ] 镜头预设（快推 / 横移 / 砸入 / 震镜）与词级卡点
- [ ] 暖调叙事插画：实测样片 → 语法卡 → 插画组件库 → 标杆项目
- [ ] 评测集与经验库

## M2 · Agent 与模型（packages/agent、packages/models、packages/voice）
- [ ] 模型目录：pi-ai 内置 + Relay（首选）+ 火山方舟 + 自定义
- [ ] 导演 Agent：分镜 → 口播 → 画面（并发）→ 全片检查，编排器强制 lint / 截图
- [ ] 配音：火山 TTS 2.0、ElevenLabs
- [ ] 无界面跑通：`frametell run <素材>` 产出一条视频，报告耗时与花费

## M3 · 面板（apps/studio）
- [ ] 本地服务：项目 CRUD、素材上传与解析、SSE 事件流、git 撤销
- [ ] 首页、新建、工作台（对话 + 工作台）、分镜确认、导出
- [ ] 设置：模型与密钥、配音、环境检查
- [ ] `/impeccable` 审查：设计、交互、状态、无障碍

## M4 · 发布
- [ ] `npx frametell` 安装体验、README、示例视频、MIT 开源

## M5 · 画布（二期）
- [ ] 每句字幕的缩略图与跳转播放
- [ ] 改一句字幕、只重配这一句
- [ ] 一句话重做某页
- [ ] 在画面上圈选区域，让 Agent 修改
