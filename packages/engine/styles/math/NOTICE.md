# Math animation · notice

The kit is original code written for Frametell Cloud. It takes its idea of the medium from the tradition of programmatic
mathematical animation (scenes written as code: axes, graphs, term-matching transforms between formulas, shape morphs);
no code from any animation library was copied.

Formulas are typeset with KaTeX (MIT licence, https://katex.org), which the engine already ships as a dependency.
