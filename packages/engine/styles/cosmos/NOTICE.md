3D Cosmos draws with three.js (MIT License, Copyright © 2010–2025 three.js authors), bundled by the engine as vendor/three.js.
The shader value noise uses the "hash without sine" idea of Dave Hoskins (MIT License, https://www.shadertoy.com/view/4djSRW).
Every planet, cloud, night-light and star texture is generated procedurally in kit.js at run time; no image files or
mission imagery are used. Physical figures (radii, orbit sizes, distances) are public scientific values (NASA planetary fact
sheets, public domain). Fonts: Inter Tight, Noto Sans SC and IBM Plex Mono (SIL Open Font License 1.1), from @fontsource.
All other code is original.
