# Notice

The pixel kit (`kit.js`) and grammar card adapt techniques from the 8-bit recipe of
[huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion): a low-resolution canvas scaled up nearest-neighbour,
checkerboard-dithered sky bands, per-sprite 1px outlines and stepped console-frame animation. No code was copied verbatim.
